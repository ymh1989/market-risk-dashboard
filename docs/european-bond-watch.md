# 프랑스·독일 국채 관찰

- 원천: 네이버 증권 국채 10년 벤치마크, `FR10YT=RR` / `DE10YT=RR`
- 일별 이력: 시장지표 prices API, 약 3년 제공. 기존 이력은 같은 원천일 때 보존
- 장중 시세: 기존 economic/bond 경로. EOD와 분리하고 관측일·시각 표시
- 방향성: 프랑스 10년(%), 독일 10년(%), 프랑스-독일 금리차(bp)
- 금리차: 같은 관측일의 프랑스 금리 - 독일 금리. %p에 100을 곱해 bp로 표시
- 카드: EOD 금리차 수준 55% + 최근 20개 공통 관측일의 양의 확대폭 45%
- 정규화: 수준은 최대 504개, 확대폭은 최대 252개의 과거 관측치 사용. 기존 40% 분위수·30% z·30% robust z 혼합 유지
- 가중치 0: 종합점수·가중 그룹점수·위험지표 수에 미반영
- 최초 60개 관측은 준비 구간. 원천 차트와 관찰점수 차트의 시작일은 다를 수 있음
- 방향성은 약 3년 이력, 카드 안의 작은 점수 그래프는 기존 카드와 동일하게 최근 120개 관측 표시

## 해석
- 두 금리가 함께 내려도 프랑스 금리가 덜 내리면 금리차 확대 가능
- 점수 하락은 금리차 축소뿐 아니라 확대 속도 둔화·과거 분포 변화로도 발생
- 재정·정치·신용 우려뿐 아니라 유동성·수급·독일 안전자산 선호가 함께 반영되는 상대가격 신호
- CDS·부도확률·프랑스 TEC10 상수만기 금리와 다른 지표. 위기 원인 단독 확정에 사용하지 않음
- 장중 금리차는 날짜가 같은 두 시세로 계산하고, 더 오래된 구성 시각을 표시. 동시 체결 보장 없음

## 갱신
- 기존 전체·빠른 갱신에서 이력과 카드 갱신, 장중 갱신에서 방향성 최신 시세 갱신
- 카드 점수는 공통일 EOD, 방향성은 더 최신인 잠정값을 별도 사용
- 텔레그램 방향성 그림도 같은 원장 사용. 아침 브리핑은 기존 정책대로 EOD 기준
