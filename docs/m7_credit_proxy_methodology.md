# M7 Credit Stress Proxy 방법론

## 목적

`M7 Credit Stress Proxy`는 무료 공개자료로 Magnificent 7 관련 스트레스가 주식·회사채·금융시스템으로 함께 확산되는지 관찰합니다.

> 본 지표는 CDS 스프레드가 아니며, 공개 시장자료를 이용해 산출한 상대적 신용 스트레스 프록시입니다.

## 실제 CDS와의 차이

- 실제 CDS 계약 가격·회수율·만기구조 미사용
- 부도확률 또는 bp 단위 스프레드 미산출
- 시장가격의 상대적 이상 움직임만 0~100으로 표준화
- 투자판단보다 시장리스크 교차확인에 사용

## 데이터 출처

| 구분 | 원천 | 사용값 | 시차·품질 |
|---|---|---|---|
| M7·ETF 가격 | Stooq 공개 CSV 우선 | 조정 가능한 일별 종가 | 자동 CSV 차단 시 기존 대시보드 가격 피드 사용·`partial` |

| 재무건전성 | SEC Company Facts | 현금·단기투자·차입금 | 공시 제출일 이후에만 사용·일별 점수 제외 |

원천 파일은 `data/raw/m7_credit_proxy/`에 atomic replace로 저장하고 Git에 포함하지 않습니다.

## 산식

### M7 고유위험

- 수익률: 일별 로그수익률
- 베타: QQQ 대비 120거래일 rolling beta
- 최소 관측치: 60일
- 일별 잔차: `종목수익률 - beta × QQQ수익률`
- 5일 잔차: 최근 5거래일 잔차 합계

산출값:

- `m7_idio_loss_5d`: 7개 종목 잔차의 중간값에 음수 부호
- `worst_member_loss_5d`: 가장 낮은 종목 잔차에 음수 부호
- `m7_dispersion_5d`: 종목 잔차의 75% 분위수와 25% 분위수 차이
- `m7_median_drawdown_60d`: 종목별 60일 고점 대비 낙폭의 중간값

유효 종목 7개는 정상, 6개는 부분 산출, 5개 이하는 M7 구성요소를 결측 처리합니다.

### 회사채 ETF

- IG 잔차: IGIB·LQD 수익률에서 IEF 대비 rolling beta 영향을 제거
- `ig_credit_loss_5d`: 두 ETF의 5일 잔차수익률 평균에 음수 부호
- `hy_ig_relative_5d`: HYG 5일 수익률에서 LQD 5일 수익률을 뺀 뒤 음수 부호

### OFR·미 국채

- OFR FSI: 시스템 스트레스 구성요소
- OFR 발표시차가 5영업일을 넘으면 점수에서 제외
- 미 국채: 5Y·10Y, 2s10s, 5s30s와 10Y 변화량을 해석용으로만 제공

## 점수와 가중치

각 구성요소는 해당 날짜까지의 최대 756거래일에서 rolling percentile로 변환합니다.

- 최소 관측치: 252거래일
- 동일값: 평균순위
- 미래 관측치: 미사용
- winsorization: 미사용

| 구성요소 | 가중치 |
|---|---:|
| M7 중간 고유손실 5D | 30% |
| 최약 종목 고유손실 5D | 15% |
| M7 중간 낙폭 60D | 10% |
| 투자등급 금리중립 손실 5D | 20% |
| HY-IG 상대약세 5D | 10% |
| OFR FSI | 15% |

결측 구성요소는 유효 가중치 안에서 재배분합니다. 원래 가중치의 70% 미만이면 종합점수를 산출하지 않습니다.

## 점수 해석

| 점수 | 구간 | 의미 |
|---:|---|---|
| 0~40 | 낮음 | 과거 대비 신용스트레스 확산 제한 |
| 40~60 | 보통 | 통상 범위 |
| 60~75 | 관찰 | 일부 구성요소 악화 |
| 75~90 | 높음 | 주식·신용시장 동반 악화 가능성 |
| 90~100 | 심각 | 과거 상위권 복합 스트레스 |

구간은 신용등급·부도확률이 아닙니다.

## 데이터 품질

- 날짜 오름차순·중복 없음
- 가격 0 초과
- 최소 252개 가격 관측치
- QQQ 거래일 기준 결합
- 가격 forward-fill 금지
- OFR·Treasury 최대 3영업일 forward-fill
- 1일 수익률 절댓값 35% 초과 시 기업행위·오류 경고
- 점수 0~100 범위
- 점수 커버리지 70% 제한
- 신규 다운로드 검증 실패 시 기존 정상 파일 유지

## 라이선스 통제

- 유료·로그인·API key 필수 원천 미사용
- 원천 자료 GitHub Pages 게시 금지
- 공개 페이지에는 파생점수·최소 시계열·출처·기준일·품질만 게시
- 기존 대시보드 가격 피드 대체 사용은 `partial` 및 운영 데이터 계약 검토 대상으로 표시

## 장애 처리

1. 임시 파일 다운로드
2. 스키마·날짜·값 검증
3. 성공 시 atomic replace
4. 실패 시 기존 정상 파일 유지
5. 이전 공개 산출물이 있으면 카드 유지
6. 이전 산출물도 없으면 카드 생략

## 알려진 한계

- CDS term structure·회수율·채권 발행사별 스프레드 미반영
- ETF 가격에는 듀레이션·유동성·배당 영향 잔존
- QQQ 시장모형은 단일요인으로 기업별 산업·팩터 노출을 완전히 제거하지 못함
- OFR FSI는 M7 전용 지표가 아니라 글로벌 시스템 스트레스
- SEC 재무정보는 분기·연간 저빈도이며 일별 점수에서 제외
- 새 관찰카드는 OOS 검증 전까지 시장 종합점수 가중치 0
