# DRAM 초기 점수 이력 검증

## 2026-10-20 장애 원인

- 15:35 전체 갱신에서 TrendForce 공식 가격 관측이 20개에서 21개로 증가
- 20일 수익률을 계산할 수 있게 되어 첫 관찰점수 1개 생성
- 기존 검증기는 모든 점수 시계열에 최소 60개를 요구하여 15:38에 게시 중단
- 폰트 경고와 ML 전방 채움 경고는 이번 종료 원인이 아님

## 검증 기준

- 공식 가격 20개 이하: 점수 미표시
- 공식 가격 N개, N ≥ 21: 점수 N−20개를 기대
- 차트 전용 과거 가격 이력은 점수 준비 상태 계산에서 제외
- 공식 가격의 날짜·중복·양수 가격·출처 및 관측 수 메타데이터 확인
- 원자료로 점수를 재계산하여 전체 점수 시계열·카드 최신값·시작일 대조
- 정상 이력이 60개 미만이면 초기 축적 안내만 표시하고 게시 허용
- 실제 누락·중복·값 불일치·조기 점수 노출은 기존처럼 게시 차단
- 다른 카드의 최소 이력 기준, 종합점수 산식 및 가중치는 변경하지 않음
