# 방향성 최신값 표시

- 방향성의 큰 숫자·그래프 끝점·마우스 값은 같은 최신 관측값을 사용한다.
- 새 날짜의 시세 또는 같은 날짜에서 확정 시각보다 늦은 시세를 잠정값으로 표시한다.
- 같은 날짜의 비교는 양쪽 모두 시간대가 포함된 관측시각이 있어야 한다. 시각이 없거나 같으면 확정값을 유지한다.
- 관측시각은 날짜까지 한국시간으로 변환한다. 미국 현지 거래일은 확정 이력과 그래프의 일자 기준으로 유지한다.
- 최신값 아래에 확정 기준일·금리를 병기한다. 잠정 구간은 점선으로 구분한다.
- 조회 실패 캐시, 미래 시각, 36시간을 넘긴 관측값은 최신값으로 승격하지 않는다. 비트코인은 기존 6시간 기준을 유지한다.
- 오프라인 HTML은 저장 당시 조회시각을 기준으로 판독한다.
- 금리차는 동일 관측일의 두 금리를 결합한다. 같은 날짜의 잠정 금리차는 두 확정 구성값보다 모두 늦게 관측된 경우만 표시한다.

확정 가격 이력·점수 산식·ML 입력에는 잠정값을 덮어쓰지 않는다. FRED 실질금리는 별도 원천 지표이므로 명목금리 최신값으로 대체하지 않는다.
