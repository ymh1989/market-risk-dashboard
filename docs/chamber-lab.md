# Field Lab 독립형 작품

## 실행과 경계

- `snow-lab.html` 도구 모음의 조리개 아이콘에서 `chamber-lab.html`로 이동
- `chamber-lab.html` 한 파일만 전달해도 실행 가능. Three.js·아이콘·스타일·라이선스 내장
- 외부 폰트·이미지·API·CDN 요청 없음. 마우스 위치를 전송하거나 저장하지 않음
- 시장 데이터, 점수 계산, 정기 갱신 및 개인 승인 봇과 독립
- 절차적으로 생성한 입체 작품이며 금융 예측 또는 물리 검증 모델이 아님
- 기존 Field Lab으로 돌아가는 링크는 함께 배포한 홈페이지에서 사용. 단독 공유본의 작품 자체는 인터넷 없이 실행

## 조작

- 마우스 이동: 주변 조각의 변위와 반사광 변화
- 클릭·터치: 곡면을 따라 퍼지는 파동
- 드래그: 시점 회전. 휠: 확대·축소
- I·II·III: 형태 선택. 자동 전개: 순차 변형
- 흐름: 움직임 속도. 일시정지: 연속 프레임 중단
- 소리: 사용자가 켠 경우에만 브라우저에서 합성. 기본 무음
- 다운로드: 실행 코드를 포함한 단일 HTML 저장

## 자원 관리

- 기본 자동 품질. 느린 프레임 누적 시 픽셀 비율과 조각 수를 단계적으로 축소
- 모바일·절전 모드는 조각 수를 축소하고 구도는 유지
- 탭 비활성화 시 렌더링·소리 중단. 페이지 이탈 시 GPU 자원 해제
- 운영체제의 움직임 줄이기 설정에서는 정지 화면으로 시작
- WebGL 사용 불가·그래픽 연결 상실 시 재시도 안내

## 재생성

수정 대상은 `src/chamber-lab.html`, `src/chamber-lab.js`. 완성본 직접 수정 금지.

```sh
python scripts/build_chamber_lab.py
python -m pytest -q tests/test_chamber_lab.py
node --check src/chamber-lab.js
```

Three.js는 기존 저장소의 고정 버전을 사용. 내장 모듈 경로 구조가 바뀌면 빌드를 중단한다.
브라우저 검증에는 별도의 개발용 `playwright`, `pngjs` 패키지가 필요하며 실제 작품 실행에는 불필요.

```sh
node tests/chamber_browser_check.cjs
```

별도 Chromium 실행 파일은 `CHAMBER_BROWSER` 환경변수로 지정 가능.
검증은 데스크톱·390/320px 모바일의 비어 있지 않은 캔버스 픽셀, 애니메이션, 드래그, 형태 전환, 일시정지, 소리 토글, 오프라인 다운로드본, 기존 입구와 콘솔 오류를 확인한다.
