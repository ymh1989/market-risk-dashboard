# 레버리지 부담·완충력 점수 진단

## 결론

- 기존 점수는 수준 위험보다 하루 자금 증감에 민감해 시계열이 과도하게 흔들렸다.
- 메인 판독값은 당일 원점수의 **과거방향 5거래일 EWM**으로 전환한다.
- 당일 원점수는 삭제하지 않고 급격한 변화 확인용 보조값으로 유지한다.
- 이 지표는 종합 시장리스크 점수에 가중치 0으로 유지한다.

## 확인 결과

분석 기간은 2021-09-09~2026-09-08, 1,226거래일이다.

| 항목 | 기존 당일 원점수 | 5D 확인점수 |
| --- | ---: | ---: |
| 하루 절대변화 중앙값 | 8.9점 | 2.3점 |
| 하루 절대변화 90분위 | 20.9점 | 6.0점 |
| 하루 최대 변화 | 61.3점 | 16.6점 |
| 원점수와 상관계수 | 1.000 | 0.907 |

기존 점수 변동의 절대 기여도는 신용잔고 일간 증감률 41.8%, 고객예탁금 일간 증감률 25.1%였다. 두 일간 흐름 항목이 전체 점수 흔들림의 66.9%를 차지했다.

## 변경 산식

1. 당일 원점수는 기존과 같이 네 구성요소를 계산한다.
2. 5D 확인점수는 `오늘 원점수 33.3% + 전일 확인점수 66.7%`로 계산한다.
3. 날짜 t의 계산에는 t까지의 값만 사용한다.
4. 당일 원점수와 확인점수의 괴리는 단기 충격의 방향을 확인하는 보조값으로 표시한다.

## 해석

- 확인점수 상승: 신용·미수 부담 확대 또는 예탁금 완충력 약화가 며칠간 이어지는 흐름
- 원점수만 급등: 당일 자금 변화가 큰 초기 경보, 지속 여부 확인 필요
- 원점수만 급락: 하루 완화 신호, 확인점수 하락이 이어지는지 확인 필요
- 확인점수와 신용/예탁금 동반 상승: 레버리지 수준과 단기 흐름이 함께 악화

## 한계

- EWM은 하루 충격을 33.3%만 즉시 반영하므로 단독 경보로 사용하지 않는다.
- FreeSIS 확정치는 장중 값이 아니며 집계 시차가 있다.
- 신용잔고 감소는 건전한 부담 완화와 급락 중 강제청산을 구분하지 못하므로 가격·breadth와 함께 판단한다.
